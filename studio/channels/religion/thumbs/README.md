## Style requirements

Match the established **cinematic, richly detailed, gold serif** thumbnail family: historical setting, warm amber rim lighting against deep navy/charcoal shadows, restrained ornamental rules, one clear focal subject, prominent 2–4 word headline legible at mobile size. Keep all lettering within the safe margins. Avoid the colorful numbered-grid look of the discarded collage. No invented scripture quotes, disrespectful caricatures, or unnecessary violence.

The existing Hinduism covers use the ornate `RELIGION UNFOLDED` identity and a framed episode number; use those as the closest layout reference for Christianity while respecting the distinct Biblical setting. The Quran covers use `THE QURAN` and a central gold headline; keep those existing covers unchanged.
